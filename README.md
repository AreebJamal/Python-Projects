# Python Projects
This repository contains a collection of Python programs and small projects that I have developed while learning and practising Python. It includes basic programming exercises, logic-building problems, simple applications, games, and creative designs using Turtle graphics.
Some projects are based on fundamental Python concepts, while others helped me explore different libraries and understand how Python can be used to build practical applications.

## Projects

### 1. Applications & Utilities

| Project | Description |
|---|---|
| [Akhbar Padhke Sunao](<AKHBAR PADHKE SUNAO.py>) | A simple news reader that fetches science-related headlines and reads them aloud. |
| [Apni Dictionary](<APNI DICTIONARY.py>) | A basic dictionary program to look up the meanings of words. |
| [Calculator](<CALCULATOR.py>) | A calculator that performs basic mathematical operations. |
| [Faulty Calculator](<FAULTY CALCULATOR.py>) | A fun calculator that intentionally gives incorrect answers for certain operations. |
| [Health Management](<HEALTH MANAGEMENT.py>) | A simple program to maintain diet and exercise records using text files. |
| [Regex Email Tracker](<REGEX EMAIL TRACKER.py>) | Finds email addresses in text using regular expressions and saves them to a file. |
| [Oh Soldier](<OH SOLDIER EXER.py>) | A file-handling exercise that uses Python's OS module to rename files. |

## Concepts & Tools Used

- **Python Basics:** Variables, data types, operators, loops and conditional statements.
- **Data Structures:** Lists, dictionaries and strings.
- **Functions:** Writing and using reusable functions.
- **File Handling:** Reading, writing and modifying files.
- **Python Modules:** `random`, `os`, `re`, `datetime` and `json`.
- **Libraries:** Turtle graphics and Requests.
- **Other Concepts:** Regular expressions, API integration and basic automation.
